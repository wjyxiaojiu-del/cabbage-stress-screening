## 项目概述

基于舟山海岛环境特点，对 **16个小白菜品种** 的 **13项生长与生理指标** 进行系统化数据分析，通过数据清洗、描述统计、方差分析（ANOVA）、加权综合评分等方法，筛选出最适合海岛环境种植的抗逆品种。

### 核心结论

| 排名 | 品种 | 综合评分 | 等级 |
|:---:|------|:--------:|:----:|
| 🥇 | **跃春** | 0.796 | 优异 |
| 🥈 | **迅雷** | 0.731 | 优异 |
| 🥉 | **信福** | 0.613 | 良好 |

- MDA、POD、脯氨酸、可溶性糖 4 项指标品种间差异均**极显著（P < 0.001）**
- 跃春脯氨酸含量最高（22.79 μmol/g），渗透调节能力最强
- 迅雷 MDA 含量最低（4.15 μmol/g），细胞膜损伤最小

## 分析方法

### 1. 数据清洗
- 统一品种名称（浙研究耐抽薹菜 → 寒秀）
- 剔除备注行与异常值
- 处理缺失数据，形成 16品种 × 19指标 标准化数据集

### 2. 描述统计
- 计算各品种 7 项生长指标 + 6 项生理指标的均值与标准差

### 3. 方差分析（ANOVA）
- 单因素方差分析检验品种间差异显著性
- 4项关键指标（MDA、POD、脯氨酸、可溶性糖）均 P < 0.001

### 4. 综合评分模型
```
综合评分 = 生理评分 × 0.6 + 生长评分 × 0.4

生理评分（权重0.6）：
  MDA（负向 0.30）+ POD（正向 0.25）+ 脯氨酸（正向 0.25）+ CAT（正向 0.20）

生长评分（权重0.4）：
  单株重（0.40）+ 株高（0.30）+ 叶绿素（0.30）
```
- 使用 Min-Max 极差标准化消除量纲差异

### 5. 可视化
- ECharts 交互式图表，支持悬停查看、缩放、主题切换
