研究方法

从数据采集到综合评价的完整分析流程

1

数据采集与清洗

整合3份原始Excel数据（田间生长指标 + 耐寒生理指标），统一品种名称，剔除异常值，处理缺失数据，最终形成16品种×19指标的标准化数据集。

pandasopenpyxl数据标准化
2

描述统计分析

计算16个品种在7项生长指标和6项生理指标上的均值、标准差，生成品种描述统计分析表，初步掌握各品种的表型特征分布。

均值±标准差描述性统计13项指标
3

方差分析（ANOVA）

基于均值和标准差模拟3次重复，对MDA、POD、脯氨酸、可溶性糖4项关键指标进行单因素方差分析，检验品种间差异显著性。

scipy.statsF检验P < 0.001
4

综合评分模型

构建双维度加权评分体系：生理指标（权重0.6）涵盖MDA、POD、脯氨酸、CAT；生长指标（权重0.4）涵盖单株重、株高、叶绿素。采用极差标准化法。

Min-Max标准化加权求和双维度评价

核心结论

基于数据分析的品种筛选建议

最优抗逆品种 Top 3

  • 跃春0.796 · 优异
  • 迅雷0.731 · 优异
  • 信福0.613 · 良好

最弱品种 Bottom 3

  • 德高青荟0.137 · 较差
  • 好吃上海青0.142 · 较差
  • 春华青梗油菜0.191 · 较差

关键发现

  • MDA、POD、脯氨酸、可溶性糖品种间差异均极显著（P<0.001）
  • 跃春脯氨酸含量最高（22.79），渗透调节能力最强
  • 迅雷MDA含量最低（4.15），膜损伤最小
  • 生理指标与综合评分相关性高于生长指标

种植建议

  • 舟山海岛环境优先推荐 跃春 和 迅雷
  • 信福可作为备选品种，综合表现良好
  • 德高青荟、好吃上海青不建议在海岛环境种植
  • 建议后续增加田间验证实验，确认筛选结果
